# 🖐️ اینستا اسکرولر | Insta Scroller

کنترل اسکرول اینستاگرام با حرکت دست، بدون نیاز به لمس موس یا کیبورد!

**Insta Scroller** یک پروژهٔ پایتونیه که با استفاده از وبکم و تشخیص حرکات دست، امکان جابه‌جایی بین ریلزهای اینستاگرام رو فراهم می‌کنه. کافیه دستت رو جلوی دوربین کمی به سمت بالا یا پایین حرکت بدی تا برنامه حرکتت رو تشخیص بده و به ریلز بعدی بره.

این پروژه بیشتر با هدف سرگرمی، آزمایش بینایی ماشین و تجربهٔ تعامل با کامپیوتر از طریق حرکات دست ساخته شده.

## ✨ قابلیت‌ها

- 🖐️ **تشخیص حرکت دست:** شناسایی موقعیت و حرکت دست با استفاده از وبکم.
- 📱 **اسکرول ریلزها:** جابه‌جایی بین ریلزهای اینستاگرام با یک حرکت ساده.
- 🎯 **کنترل مبتنی بر اشاره:** پس از هر حرکت، دستت رو به موقعیت عادی برگردون تا بتونی حرکت بعدی رو انجام بدی.
- 🧩 **ساختار ماژولار:** تفکیک بخش‌های مختلف برنامه برای خوانایی بهتر و توسعهٔ آسان‌تر.
- 🖥️ **بدون نیاز به سخت‌افزار اضافی:** فقط به یک وبکم و کامپیوتر سازگار نیاز داری.

## ⚙️ فناوری‌های استفاده‌شده

| کتابخانه | کاربرد |
|---|---|
| [Python](https://www.python.org/) | زبان برنامه‌نویسی پروژه |
| [OpenCV](https://opencv.org/) | دریافت و پردازش تصویر وبکم |
| [MediaPipe](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker) | تشخیص دست در تصویر |
| [PyAutoGUI](https://pyautogui.readthedocs.io/) | شبیه‌سازی ورودی برای کنترل اسکرول |

## 📋 پیش‌نیازها

قبل از اجرای پروژه، مطمئن شو موارد زیر رو داری:

- **سیستم‌عامل:** ویندوز ۱۱
- **Python:** نسخهٔ 3.11
- **وبکم:** وبکم داخلی لپ‌تاپ یا وبکم خارجی
- **مرورگر:** مرورگری که بتونی از طریق اون وارد اینستاگرام بشی

> **نکته:** نسخهٔ `0.10.14` از MediaPipe در این پروژه استفاده می‌شه. محیط پیشنهادی برای اجرای پروژه Python 3.11 هست؛ نسخه‌های دیگر ممکنه به بررسی سازگاری نیاز داشته باشن.

## 🚀 نصب و راه‌اندازی

### ۱. دریافت پروژه

مخزن رو از گیت‌هاب دانلود کن یا با دستور زیر کلونش کن:

```bash
git clone YOUR_REPOSITORY_URL
cd YOUR_PROJECT_DIRECTORY
```

`YOUR_REPOSITORY_URL` و `YOUR_PROJECT_DIRECTORY` رو با آدرس مخزن و نام پوشهٔ واقعی پروژه جایگزین کن.

### ۲. ساخت محیط مجازی (پیشنهادی)

برای اینکه کتابخانه‌های پروژه با سایر پروژه‌های پایتون تداخل نداشته باشن، بهتره یک محیط مجازی بسازی:

```bash
python -m venv .venv
```

فعال‌سازی محیط مجازی در ویندوز:

```powershell
.venv\Scripts\activate
```

### ۳. نصب کتابخانه‌ها

بعد از فعال‌سازی محیط مجازی، دستور زیر رو در ترمینال اجرا کن:

```bash
python -m pip install opencv-python mediapipe==0.10.14 pyautogui
```

### ۴. اجرای برنامه

در پوشهٔ اصلی پروژه، دستور زیر رو اجرا کن:

```bash
python main.py
```

## 🎮 نحوهٔ استفاده

۱. برنامه رو اجرا کن و مطمئن شو وبکم به‌درستی کار می‌کنه.

۲. مرورگر رو باز کن و وارد اینستاگرام شو.

۳. به بخش ریلزها برو و روی صفحه کلیک کن تا مرورگر فوکوس داشته باشه.

۴. دستت رو در محدودهٔ قابل‌مشاهدهٔ وبکم قرار بده و برای لحظه‌ای ثابت نگه دار.

۵. دستت رو به سمت بالا یا پایین حرکت بده تا برنامه حرکت رو تشخیص بده و به ریلز بعدی بره.

۶. بعد از هر حرکت، دستت رو به موقعیت عادی برگردون تا برای اشارهٔ بعدی آماده بشی.

برای بستن برنامه، کلید **`Q`** رو بزن.
